# 悠悠有品饰品折扣率计算

## 概述

在悠悠有品（youpin898.com）的饰品市场页与饰品详情页，直接显示该饰品「倒余额」的折扣率：用人民币在悠悠有品买入，再挂到 Steam 社区市场卖出并扣除手续费后，能换回多少 Steam 余额。

脚本不额外发起请求，而是拦截页面自身的接口响应，复用响应里已有的悠悠有品价格与 Steam 价格来计算。

## 功能特性

- **市场列表页**（`/market`）：在每个饰品卡片的标签行末尾附加折扣率标签，按档位换色
- **饰品详情页**（`/market/goods-list`）：在价格区域插入「折扣」信息
- **三档配色**：低于 80% 绿色（值得倒），80%～100% 黄色（基本持平），高于 100% 红色（倒余额反而亏）
- **点击跳转**：市场页的折扣标签本身就是链接，点击直达该饰品的详情页（建议中键点击，可以保持原界面不调整新标签页打开）

## 折扣率怎么算

```text
折扣率 = 悠悠有品售价 ÷ (Steam 售价 × 0.85)
```

其中 `0.85` 是 Steam 社区市场成交后扣除 15% 手续费的实际到手比例。

折扣率越低越划算：`60%` 表示花 0.6 元人民币能换到 1 元 Steam 余额；超过 `100%` 则说明这笔倒余额是亏的。

> 档位阈值见 `src/module/marketPage/parseDiscountData.ts` 中的 `LOWER_DROP_PRICE_PERCENT = 0.8`。

## 使用方法

1. 安装网页拓展 [脚本猫](https://scriptcat.org/zh-CN)
2. 点击脚本详情页的 **安装脚本** 按钮
3. 打开 <https://www.youpin898.com/market> 或任意饰品详情页，等列表数据加载完成后即可看到折扣标签

## 说明

- 匹配范围：`https://www.youpin898.com/*`，在 `document-body` 阶段运行
- 详情页的悠悠有品售价取自「外观」筛选中当前外观对应的价格；若该价格为 0，则回退读取页面价格区域显示的第一个价格
- 折扣率仅供参考，Steam 市场价格波动、交易冷却与挂单成交速度都会影响实际到手余额
